# URL Synopsis AI

An AI-powered application that generates comprehensive synopses from any URL — YouTube videos, articles, blogs, documentation, research papers, and more.

## Status
🚧 Under active development — built step by step as a learning project.

## Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend:** Node.js, Express, TypeScript
- **AI:** OpenAI API (swappable to Anthropic)
